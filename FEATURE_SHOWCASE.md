## ???? User Flow

### Viewing Provider Profile
1. User visits `/search`
2. Browses providers (sorted by rating)
3. Clicks "View Profile" button
4. Sees complete provider information
5. Reads reviews from other users

### Submitting a Review
1. User logs in (if not already)
2. Navigates to provider profile
3. Clicks on stars to select rating (1-5)
4. Optionally writes a comment
5. Clicks "Submit Review"
6. Rating updates automatically
7. Review appears in the list

### Editing a Review
1. User visits provider they reviewed
2. Sees their review in the form
3. Changes rating or comment
4. Clicks "Update Review"
5. Changes saved immediately

### Deleting a Review
1. User visits provider they reviewed
2. Clicks "Delete Review" button
3. Confirms deletion
4. Review removed
5. Rating recalculated
